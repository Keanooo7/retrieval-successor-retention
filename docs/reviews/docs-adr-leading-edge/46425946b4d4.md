## Q11: checking the general forms from the formulas

Sentence `i` is written at step `i`. Steps run from `0` to `S−1`. `e` is the eviction step, with
`i < e ≤ S−1`, or `e = ∞` if the sentence is never evicted.

- **Evicted** (`e ≤ S−1`):
  - A = `1 + (e − i)`;
  - B = `e − i`;
  - **A − B = 1.**
- **Censored** (`e = ∞`):
  - A = `1 + (S − 1 − i)` = `S − i`;
  - B = `S − i`;
  - **A − B = 0.**

Consequences:

- **A agrees with D7.** For evicted sentences A is D7's `k_i = 1 + (e − i)`, and for censored ones it
  is D7's `1 + (S − 1 − i)`.
- **B reduces as claimed.** Under FIFO, `e = i + M`, so B = `min(i + M, S) − i` = `min(M, S − i)`.
- **Ranks within each group are unchanged.** A − B is constant inside each group, so the difference
  between two evicted sentences, or between two censored ones, is the same under A and B.
- **Differences across the groups shift by exactly 1.** Every evicted-minus-censored difference is 1
  smaller under B than under A. So the ADR's statements about ties and the sign of gaps hold.
- **The FIFO case is right.** At `i = S − M` the sentence is censored, because `i + M = S > S − 1`,
  and it scores `M` under both conventions. The evicted sentences score `M + 1` under A and `M`
  under B. So the ADR's statement is correct.
- **The synthetic case is right.** With `S = 48` and `M = 16`, `i = 32`.

**Every Q11 statement verifies.**
