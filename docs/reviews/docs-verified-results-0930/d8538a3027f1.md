## MINOR

### n-1: A null nested inside a list value still prints as `None` with rc 0.

**Where:** `scripts/verified_results.py:288-291`, `seeds()` `:335` and `labels()` `:339`.

The M-1 fix refuses a null only when the resolved value is itself None. A null inside
a resolved list or dict passes through. `seeds()` and `labels()` then `str()` it.

I ran my scratch doctor on two cases. In both, `--check` gave rc 1 against the
committed file.

| doctored case | `--stdout` rc | rendered |
|---|---|---|
| B5 `B.ckpt9000.R_quantity.samples[1] = None` | **0** | row 38: `0.8683 / None / 0.8573` |
| E0d `e0d.labels.value[1] = None` | **0** | row 1: `labels AGREE / None / AGREE` |

`--write` takes the same path, so it would also exit 0. This breaks the module's
promise (`:21-22`) that a missing source is "`3`, never a row with a blank in it".
It is the class of defect M-1 named, one level down.

A null sample is plausible in a future ledger, for example an unrun seed. Today's
output is unaffected: the pins are immutable and every nested value is non-null. A
drifted re-pin would still go red under `--check`, with rc 1. So this does not block.

**Fix:** make the null check in `resolve` recursive over lists and dicts. Add a
`null-inside-a-list` case to `DOCTORED`, and a battery mutation for it.

### n-2: The new tag test has no battery mutation, and its docstring says "on origin" when it checks local refs.

**Where:** `tests/test_verified_results.py:7-11` and `:88-106`; `scripts/mutation_battery.py`.

`grep test_every_unmerged_pin scripts/mutation_battery.py` finds nothing. Gauntlet
1.7 requires that "a new check is not believed until a mutation has shown it red".

The test can fail: a wrong or absent `tag=` fails it. But no mutation has shown it
red. It also runs `rev-parse` against the local repo. A tag that exists locally but
was never pushed passes, although the module docstring says the pins "are protected
by the annotated tags … on origin". Both tags are on origin today; I checked with
`ls-remote`.

**Fix:**
- Add a mutation, for example `tag="verified/b5-deaeaa6"` → `tag=""`, gated on this
  test.
- Either say "local tags (pushed to origin separately)" in the docstring, or accept
  it as documented.
