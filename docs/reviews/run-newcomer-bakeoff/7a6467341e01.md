- **Fix:** return UNRESOLVED when either CI is flagged, and add a case to `test_dq2`.

### N2 (MINOR): the EVAL unit key hashes only the newcomer `run.py`

- **Where:** `run.py:765-774`.
- **What:** most of the measurement code is B2's `run.py`, imported by path and still being edited on `run/b2-psi-probe`, plus `src/rsr/model/tg/policy_loop.py` and `src/rsr/baselines/lru.py`. None of these is in `unit_key`. A relaunch after such an edit would resume units measured by different code.
- **Effect on the data:** none (`n_resumed: 0` in all 12 shards).
- **Fix:** add the sha256 of B2's `run.py` and the policy-loop and baseline files, or the git tree hash, to `unit_key`.

### N3 (MINOR): the fit resume key has no code hash, and the fit file save has no fsync

- **Where:** `run.py:709-716`, `723`, and `488-492`.
- **What:** `fit_key` is (format, seed, prereg, b2 sha, N_F). Changed fit code would reuse an old `fit-seed{s}.pt`. `atomic_torch_save` does `os.replace` without fsync.
- **Fix:** add `code_sha256()` to `fit_key`, and fsync before the replace.

### N4 (MINOR): reproduction depends on untracked files in another worktree

- **Where:** `run.py:495-514`.
- **What:** `b2_fits_dir()` defaults to `<main>/.worktrees/b2-psi-probe/runs/b2-psi-probe-fit/phaseA/*.pt`, which git does not track. The sha pins catch a wrong file but not a missing one.
- **Effect after merge:** a rerun or `aggregate` from main needs that worktree kept, or `RSR_NB_B2_FITS`.
- **Fix:** state the dependency in RESULTS.md, or copy the pinned files to a durable path such as `~/rsr-substrate`.

### N5 (MINOR): the grace "no graph" guard is vacuous

- **What:** `psi.requires_grad` is read inside `torch.no_grad()`, where it is always False. The real guarantee is `ProbeArgminPolicy`'s detached fp64 score.
- **Fix:** compute or check the score outside `no_grad`, or drop the guard and cite the inner policy.
