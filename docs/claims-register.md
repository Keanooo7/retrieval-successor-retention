## How to read a row

- **value per seed / CI per seed**: from the cited ledger key (or raw record field). Display rounds to 4 decimals; the full value is at the key. Every CI is per seed; no CI is pooled across seeds. `n/a` = the run computed no CI for that number.
- **PREREG'd**: the number (statistic, data, rule) is named in a PREREG or amendment committed before the run that produced it. **EXPLORATORY**: it is not.
- **UNSEEN**: no value of this quantity on this data had been read when its analysis was fixed. **SEEN**: one had (a post-hoc or descriptive reading, or data already inspected for this quantity). The reason is given per row.
- **re-derived equal**: every check's output string-equals the ledger value in full precision. Check kinds: `raw` = recomputed from per-document / per-seed raw records through the run's own analysis code; `archive-ledger` = read from the run's own out-root ledger in the archive (not the committed copy); `ledger` = read of the committed key only (proves the register reads the right key; recomputes nothing). A mismatch is reported in the row, never smoothed.
