## 1. Why this plan (the evidence; every number was re-read from ledgers on 2026-10-19)

- **Run 2 is FAILS** (verified at `9c432b6`).
  - ψC − FIFO all-query accuracy is −0.072 / −0.045 / −0.083, and every paired per-document 95% CI excludes 0.
- **ψC is below random** (`run2-vs-random`, `6ed6583`): −0.047 / −0.022 / −0.038.
- **ψC loses on its own objective.** Held-out real-token NLL:

  | | seed 0 | seed 1 | seed 2 |

  | ψC | 1.417 | 1.395 | 1.431 |

  Source: `measure-seed*.json` `heldout.nll.real`.
- **The learned age-only head equals FIFO.** Its accuracy and NLL are identical on every seed.
- **The frozen reader can use memory that is not in FIFO order.** Oracle-policy accuracy is 0.922 / 0.912 / 0.928, against FIFO's 0.775 / 0.767 / 0.803.
- **The least-squares optimum of ψ̂'s class misses** (`320c58a`).
  - Cap 0.39 / 0.53 / 0.35 on U-val, and 0.41 / 0.55 / 0.39 in-sample.
  - Caveat: it was fitted on FIFO-world Δ, not on-policy.
- **A kind-mean ranking scores cap +1.00 / −0.95 / +1.00** (B0 `ko`, content-only, random tie). That is a 3-number rule beating the least-squares optimum on 2 of 3 seeds. Hypothesis: the binding constraint is the objective (squared error, then argmin), not capacity.
- **Expire-Span − FIFO is +0.006 / −0.046 / −0.004.** Every CI excludes 0, but the sign is mixed. The wording is "small and inconsistent in sign", **not** "no detectable difference".

- **Finding 1 is a hypothesis for phase 1c, not a result.**

### Phase 2: the ranking-loss test (GO, under Gate P2; Tier G)

- **Its own PREREG**, committed alone, before any phase-2 code or data.
- **Reviews:** one Tier G review of the PREREG and code together, plus at most one confirming round.
- **Checks:** the full suite at the exact launch head, and `rsr-verifier` per run.
- **Fixed now, so the PREREG cannot loosen it:**
  - **Same as run 2 except the loss:**
    - the content-only `BilinearValueHead` (16,640 features);
    - no age in ψ̂;
    - no gradient into the transformer or `W_sent`;
    - frozen arm B ckpt3000;
    - LOO-resample Δ at γ = 0.9;
    - b off, shadow off.
  - **The only change is the loss.**
    - Primary: a within-step pairwise logistic loss over slot pairs ordered by G, with the pairs that involve the step's true bottom-k up-weighted.
    - At most ONE secondary loss, pre-specified.
    - The PREREG fixes k, the weighting and a small hyperparameter grid.
    - The selection criterion on the **fresh tuning split** is the cap, never EVAL.
  - **The default config must reproduce run 2.** A test asserts that the loss switch off is bit-equal to run 2's L_MC path, the same pattern as run 2's test against run 1.
  - **Attempt count:** this is attempt 3 at a learned content-only policy (after run 1 and run 2). Every configuration fitted is reported.
- **2a (offline):**
  - Fit on the B0-CF Δ (`cf-ceiling/runs/cf-ceiling/raw/B-ckpt3000-seed*.delta.pt`, uncensored, FIFO-world), as offline-psi did.
  - Deploy frozen on the **already-used** EVAL `[995000, 997048)`, so it is comparable to offline-psi and run 2, and is labelled as such.
  - Run 2's WIN / LOSS / EQUIV rule with δ_seed.
  - **Proceed to 2b iff WIN on all 3 seeds.** Otherwise stop: the result is "structurally hard", and the next stop is Gate A.
- **2b (on-policy run 3):**
  - Run 2's harness with the ranking loss.
  - Step count and projection are fixed in the PREREG. Run 2 was still improving at 3000 steps, so the PREREG must justify its choice from a smoke test, not from this sentence.
