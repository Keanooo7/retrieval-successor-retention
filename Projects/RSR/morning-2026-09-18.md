## 🔴🔴 The single highest-value next experiment

**Nothing in the objective rewards two sentences having different gestalts.** Across cycles 11 and
13, deleting the whole memory costs ≈0% of the loss in every arm tried, and there is **no gradient
pressure toward gestalt diversity anywhere in the training path.** That is a mechanism, not a scale
effect, and it is cheaper to test than scale.

Add a contrastive term over within-document gestalts — or weight the loss to real-token positions so
the ~58 pad positions per sentence cannot dominate — retrain identically, re-run the memory ablation.
~16 min of CPU per arm, same harness, no `src/` change.

**Either outcome is decisive.** If the memory stays inert under a term that *explicitly* forces
diversity, **the memory path itself is broken** — wiring or gate — and every E1/E3 reading would be
about a model whose memory does nothing. If it goes live, the collapse is an objective problem and the
fix is known. **This must be settled before E1 is read as evidence about anything.**

## The shape of the night, in one paragraph

The first three cycles found that **RSR does not exist as a runnable arm** — `policy_name` is a label
with no mechanism, `ProtectionBias` and `_score` describe different objects, and `attribution` is a
config echo that cannot answer the question §3.4 asks of it. Cycles 5–9 then took the one thing that
*is* implemented — the eviction score — and established that `b`'s authority is governed by an **order
statistic** nobody had costed: the top-2 z-margin, which no single frozen `b_max` can serve across `M`,
which redundancy moves more than `M` does, and which §3.4's `ν` term **provably cannot** repair because
its penalty is equal within a duplicate pair to float32 precision. Cycles 10–13 asked whether any of
that matters and hit the floor: the tie is expensive when the answer lives in the residual, **but the
model this repo trains has no usable memory at all** — gestalts collapse to a 1.3-dimensional space and
deleting all 16 slots costs 0.03% of the loss. **The retention machinery is being tuned above a memory
that does nothing.** That is the finding the night converges on, and it is why the contrastive-term
experiment outranks every open registry decision above it.
